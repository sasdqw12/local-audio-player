# 本地音频播放器 - 一键构建APK教程

## 🚀 零代码5分钟生成APK方法（推荐）

你不需要在本地安装任何编译环境，按照以下步骤操作就能直接下载现成的APK：

### 步骤1：注册/登录GitHub账号
访问 https://github.com 注册一个免费账号，已登录可跳过。

### 步骤2：创建新仓库
1. 点击右上角「+」→「New repository」
2. 仓库名称填写 `audio-player`，选择「Public」公开
3. 点击「Create repository」创建

### 步骤3：上传所有文件
将压缩包里的**所有文件**（包括`.github`文件夹、`main.py`、`buildozer.spec`等）直接拖到仓库页面上传，然后点击「Commit changes」。

### 步骤4：等待自动构建
1. 上传完成后，点击仓库顶部的「Actions」标签
2. 你会看到一个名为「Build Android APK」的任务正在自动运行
3. 等待大约15-20分钟，任务会变成绿色✅表示完成

### 步骤5：下载APK
1. 点击完成的构建任务，在页面底部的「Artifacts」区域
2. 点击「本地音频播放器APK」即可下载编译好的安装包
3. 下载后解压得到apk文件，传到手机即可安装使用

## 📱 APP功能说明
✅ 选择任意目录，自动扫描目录下所有音频文件  
✅ 支持mp3/wav/ogg/m4a/flac/aac等主流格式  
✅ 列表循环/单曲循环/随机播放三种模式  
✅ 进度条拖动，上一首/下一首/播放暂停控制  
✅ 自动记住上次选择的目录  
✅ **完全无广告，纯本地运行，不需要任何网络权限**

## ⚠️ 注意事项
- 安卓13及以上系统首次运行会请求存储权限，请点击允许才能正常扫描音频文件
- 建议将音频文件放在手机「音乐」目录或者Download目录下，方便查找
- 如果播放没有声音，请检查系统媒体音量是否开启
